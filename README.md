### Product boundaries

- The project descriptions are summaries of repository documentation and implemented scope, not proof of live customer deployments.
- Private project repositories are intentionally **not linked** as public demos.
- Medical AI features assist with **operational** analysis and do not offer clinical diagnoses or medical certification.
- The migrator's static validation does not guarantee runtime compatibility; database and workflow tests remain necessary.
- The project inventory managerial AVCO calculation does not modify native Odoo stock valuation or accounting.
- HR settlement review is not payroll or payment execution.

## Local preview

Open `index.html` in a browser, or serve the directory through a local static-file server. No build step or backend is required. The contact form opens an email draft via `mailto:`.

## Deployment

The existing GitHub Pages workflow publishes updates from `main`. This repository may be private while the published portfolio page remains publicly accessible, according to the GitHub Pages configuration.
